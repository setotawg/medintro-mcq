MEDINTRO QUESTION BANK STARTER

Files:
- index.html: reusable practice website interface
- question-bank/microbiology.json: all 80 microbiology MCQs, answers, and explanations

Deploy: upload index.html and the entire question-bank folder to the root of your GitHub Pages repository. Keep the relative paths unchanged.

To add questions later: add them to the questions array in a new JSON file following the same structure, then add a selector or update BANK_URL in index.html. The current page loads microbiology.json.

This is a static practice site. Scores are calculated in the browser and not saved or uploaded.
